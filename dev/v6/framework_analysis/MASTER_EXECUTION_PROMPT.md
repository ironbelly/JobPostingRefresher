## Critical Success Factors

### Must-Have Qualities:
1. **Zero Ambiguity**: Every task must be executable without interpretation
2. **Complete Context**: All information needed must be inline, not referenced
3. **Progressive Validation**: Errors caught at multiple stages, not just QA
4. **Backward Compatible**: Existing .gfdocs workflows must continue working
5. **Scalable**: Must handle both simple and complex projects elegantly

### Red Flags to Avoid:
❌ Descriptive instructions instead of executable commands
❌ External context references instead of inline embedding
❌ Post-execution-only validation
❌ Breaking changes to existing workflows
❌ Overcomplicated systems that reduce usability
❌ Missing error handling and recovery procedures
❌ Insufficient testing and validation

### Success Indicators:
✅ Tasks contain `bash` code blocks with exact commands
✅ Validation commands included at multiple points
✅ Context embedded with examples and expected outputs
✅ Dependencies explicitly declared
✅ Parallel opportunities identified
✅ Quality metrics consistently exceed targets
✅ Agent execution succeeds on first attempt
